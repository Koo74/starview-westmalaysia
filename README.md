## ✨ Features

- 🗺️ **500+ locations** across all West Malaysian states (Perlis to Johor)
- 🌫️ **Haze & fog detection** — seasonal haze calendar + tropical fog detection
- 💨 **Live air quality** — PM2.5, PM10, AQI from Open-Meteo CAMS model
- 🏞️ **18 protected dark-sky zones** — Gunung Nuang, Genting, Cameron, etc.
- 🌙 **Moon phase** & **Milky Way visibility** calendar
- 📸 **Activity-specific scores** — naked-eye / telescope / astrophotography
- 📊 **Export reports** — CSV + JSON with full data audit trail
- 🧠 **Agent memory** — remembers previous analyses, learns optimal parameters
- 🗺️ **Interactive map** — click any point, get instant analysis
